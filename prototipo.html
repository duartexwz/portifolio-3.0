Fintech Dashboard

Plataforma de gestão financeira e acompanhamento de investimentos.

Ver projeto ao vivo
ClienteNexo Finance
Ano2025
PapelDev & Design
Duração5 meses

O desafio

O cliente precisava unificar dados de diferentes fontes em um painel único, com atualização em tempo real e leitura simples para usuários sem conhecimento técnico.

A solução

Criei uma interface modular com filtros inteligentes, gráficos interativos e uma API que consolida as informações. O design system garante consistência entre as áreas do produto.
